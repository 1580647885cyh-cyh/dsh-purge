# 独立维护 1.1.71 的宿主兼容性

用户选择以当前正在使用的本地 1.1.71 为保护基线，保持版本号和远程更新锁，仅为适配 DeepSeek Harness 的变更修复兼容缺陷。原作者后续版本用于核对缺陷和理解宿主变化，候选修复逐项评估后纳入本地维护版。此选择需要独立维护和回归验证。

## 已确认的边界

- 内核按正常工作时的功能语义验收：保留保护基线的提示词与规则、工具能力及参数语义、既有功能和默认行为。
- 允许为兼容修改相关实现文件，包括 core.js；每项改动都应说明兼容故障、修复内容和行为保留的验证证据。
- 第一轮验收 Windows 官方桌面 DSH 0.2.1-rc.5。Web 端和其他宿主版本后续分别定义验收范围。
- 兼容缺陷来源包括上游发现和本地独立发现。独立发现的问题须能复现，并能证明属于宿主兼容缺陷。
- 若某项宿主适配无法同时保持原有功能语义，记录具体冲突并等待用户决定，不自动用行为变化换取可运行。

## 验收原则

对具体故障建立可复现的检查，并验证修复后的宿主加载、调用或运行结果；同时针对该改动可能影响的基线行为做回归检查。仅能启用插件、版本号相同或补丁状态显示成功，均不足以证明兼容且保持原有行为。
