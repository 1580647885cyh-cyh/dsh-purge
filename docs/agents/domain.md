# 领域文档

本项目采用单一上下文：根目录 `GLOSSARY.md` 保存领域术语，`docs/adr/` 保存架构决策。

## 阅读时机

探索代码、编写规格或任务前，若根目录已有 `GLOSSARY.md`，先读取并沿用其中术语。
修改某个领域前，读取 `docs/adr/` 中与该变更相关的决策。
这些文件或目录尚不存在时，直接继续；由 domain-modeling 在术语或重要决策明确后按需创建。

## 内容约定

术语表只记录领域概念及其区别，实施计划和代码细节放在规格中。
只有存在真实权衡、改变代价较高且缺少背景容易误解的决策，才记录 ADR。
拟议方案与既有 ADR 冲突时，明确指出具体决策和冲突原因。
